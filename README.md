# DKF-CAREER : site vitrine

Site statique de présentation de DKF-CAREER, assistant personnel de recherche d'opportunités professionnelles (stages de fin d'études, alternances, premiers emplois) dans le génie civil et le BTP.

Ce dépôt contient **uniquement** le site vitrine : aucun code de l'application, aucune clé d'API, aucune donnée personnelle.

## Contenu

- `index.html` : page unique (accueil, présentation, fonctionnalités, sources, confidentialité, contact).
- `404.html` : page d'erreur.
- `assets/style.css`, `assets/favicon.svg` : mise en forme et icône.

Aucun JavaScript, aucune police ou ressource externe, aucun cookie, aucun outil de mesure d'audience.

## Publication

Hébergement : GitHub Pages, branche `main`, dossier racine.
